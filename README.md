32-bit ALU Design and Verification

Internship: Vaidsys Technologies  
Domain: VLSI Design and Verification  
HDL: SystemVerilog

Project Objective

Design and verify a 32-bit combinational Arithmetic Logic Unit supporting arithmetic, logical, shift and comparison operations.

Supported Operations

- Addition and subtraction
- AND, OR, XOR and NOT
- Logical left and right shifts
- Signed and unsigned comparisons

Verification Approach

The project will use directed testing, boundary-value testing, an independent reference model, self-checking comparisons and randomized regression.

Tools

- SystemVerilog
- Icarus Verilog 
- GTKWave
- Yosys

Project Status

Day 1: Specification and simulation environment setup.

Implementation and verification results will be documented as the project progresses.
